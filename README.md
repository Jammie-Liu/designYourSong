# designYourSong · 偶像風格音樂實驗室

You can choose a style of a group or a singer and adjust an original song generated by Strudel based on it.

選一位歌手的風格，拖拉滑桿、開關音軌，即時聽到「如果用這位歌手的風格做一首歌，會是什麼聲音」。所有音樂都是在瀏覽器裡用程式碼即時生成的原創循環。

- **線上試玩**：<https://jammie-liu.github.io/designYourSong/>
- **專案設計**：功能、風格模組分析、運作方式與視覺設計，請見 [DESIGN.md](DESIGN.md)

## 什麼是 Live Coding？

Live coding（即時編碼）是一種**用寫程式來演奏音樂**的方式。一般作曲是先寫好再播放；live coding 則是讓一段循環中的音樂**邊播邊改**：表演者打一行程式碼，聲音就跟著變，寫程式本身就是演奏。

現場表演時，表演者通常會把程式碼投影出來給觀眾看。這類以演算法即興的音樂派對稱為 **Algorave**（algorithm + rave）。

例如以下這段程式碼會播出一段有鼓、貝斯和和弦的循環。改掉 `.lpf(800)` 的數字，聲音就會立刻變亮或變悶：

```javascript
stack(
  s("bd*4, [~ sd]*2, hh*8"),          // 大鼓、小鼓、hi-hat
  note("<c3 a2 f2 g2>").s("sawtooth")  // 貝斯走和弦根音
    .lpf(800),                         // 濾波器
  note("<[c4,e4,g4] [a3,c4,e4] [f3,a3,c4] [g3,b3,d4]>").s("triangle")
)
```

這個專案把 live coding 包裝成一般人也能操作的介面：使用者不用懂程式，透過按鈕和滑桿操作，背後就是在即時改寫 Strudel 程式碼。想體驗真正的 live coding，可以展開網頁下方的「程式碼面板」，直接修改後按「執行」。

## 使用的技術

| 技術 | 用途 |
| --- | --- |
| [Strudel](https://strudel.cc) | 在瀏覽器中執行的 live coding 音樂環境，是 [TidalCycles](https://tidalcycles.org) 的 JavaScript 版本。本專案透過 `@strudel/web` 套件產生並播放所有音樂 |
| Mini-notation | Strudel 的節奏語法，用短字串描述節奏，例如 `"bd ~ sd ~"` 代表「大鼓、休止、小鼓、休止」，`*8` 代表重複八次 |
| [Web Audio API](https://developer.mozilla.org/docs/Web/API/Web_Audio_API) | 瀏覽器內建的音訊引擎，Strudel 用它即時合成鋸齒波、方波、三角波等音色，並處理濾波與殘響 |
| [Dirt-Samples](https://github.com/tidalcycles/Dirt-Samples) | TidalCycles 社群的開源鼓組音色庫，提供大鼓、小鼓、hi-hat、拍手等聲音 |
| HTML / CSS / JavaScript | 介面與互動邏輯，依作業規定全部寫在單一 `index.html` |
| [GitHub Pages](https://pages.github.com) | 免費部署靜態網頁，push 之後自動更新線上版本 |

### 音樂是怎麼產生的

1. 每位歌手是一個「風格模組」，記錄 BPM、鼓組型態、和弦進行、音色等風格要素
2. 使用者每次操作，程式就依模組與滑桿數值組出一段新的 Strudel 程式碼
3. Strudel 解析這段程式碼，在不中斷節拍的情況下換上新的聲音

細節請見 [DESIGN.md](DESIGN.md#運作方式)。

## 如何使用

1. 開啟[線上版本](https://jammie-liu.github.io/designYourSong/)，或下載 `index.html` 後用 Chrome 開啟
2. 選一張歌手卡片，按「播放」
3. 調整速度、能量、亮度、空間感，或開關各音軌，聽聽差別

需要網路連線，因為 Strudel 與鼓組音色是從網路載入。請不要在檔案預覽視窗中開啟，預覽視窗通常會擋下外部程式。
